📱 Projeto Android - Site Institucional e Histórico do Mascotinho

Site desenvolvido com foco em responsividade e design moderno, criado durante os estudos de desenvolvimento web. O projeto apresenta a história do Bugdroid (o famoso mascote do Android) e diversas curiosidades sobre as versões do sistema operacional em uma interface limpa e intuitiva.

🚀 Tecnologias Utilizadas:

HTML5 & CSS3 (Mobile First / Design Responsivo)

Git & GitHub (Controle de versão e hospedagem via GitHub Pages)
